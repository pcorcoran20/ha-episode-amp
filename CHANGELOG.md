# Changelog

## 1.0.0

Initial release.

- Local push control of Episode Response Series amps (2D / 8D / 12D / 16D) over the TCP JSON API
- Per-zone `media_player` (volume, mute, Source 1)
- Per-zone selects: DSP preset, Stereo/Mono, Source 2, Output group
- Per-zone numbers: Max volume, Turn-on volume
- Auto-reconnect with backoff and a keepalive poll
